- `dashboard/`: Berisi skrip aplikasi Streamlit (`dashboard.py`) dan dataset bersih (`main_data.csv`).

- `requirements.txt`: Kebutuhan dependensi Python.
- `url.txt`: Tautan live dashboard di Streamlit Community Cloud.
